      Comment jouer ? +

      Retrouvez les quatre couleurs du code secret, dans le bon ordre. Il est tiré au hasard parmi les six couleurs de la palette et reste fixe pendant la partie.

      1. Composez votre proposition de la position 1 à la position 4. Une couleur peut apparaître plusieurs fois.
      2. Modifiez vos choix autant que vous le souhaitez, puis validez. Une proposition incomplète est refusée sans consommer d’essai.
      3. Lisez les indices : bien placée signifie bonne couleur à la bonne position ; mal placée signifie couleur présente ailleurs dans le code.
      4. Chaque occurrence compte une seule fois : les bien placées d’abord, puis les mal placées parmi les couleurs restantes. Les indices ne disent pas quelles positions sont concernées.
      5. Vous gagnez avec quatre couleurs bien placées, même au dixième essai. Après dix propositions incorrectes, la partie est perdue.

      Après la fin, vos essais restent consultables. « Nouvelle partie » tire un code et efface essais, historique et indices.
