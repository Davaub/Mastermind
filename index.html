      Comment jouer ? +

      Retrouvez les quatre couleurs du code secret, dans le bon ordre. Il est tiré au hasard parmi les six couleurs de la palette et reste fixe pendant la partie.

      1. Composez votre proposition de la position 1 à la position 4. Une couleur peut apparaître plusieurs fois.
      2. Modifiez vos choix autant que vous le souhaitez, puis validez. Une proposition incomplète est refusée sans consommer d’essai.
      3. Lisez les indices : bien placée signifie bonne couleur à la bonne position ; mal placée signifie couleur présente ailleurs dans le code.
      4. Chaque occurrence compte une seule fois : les bien placées d’abord, puis les mal placées parmi les couleurs restantes. Les indices ne disent pas quelles positions sont concernées.
      5. Vous gagnez avec quatre couleurs bien placées, même au dixième essai. Après dix propositions incorrectes, la partie est perdue.

      Après la fin, vos essais restent consultables. « Nouvelle partie » tire un code et efface essais, historique et indices.

      Installer Code secret +

      Retrouvez le jeu avec son icône sur votre écran d’accueil ou dans vos applications. L’installation est facultative ; vous pouvez continuer à jouer dans le navigateur. Une connexion Internet reste nécessaire pour ouvrir le jeu.

      Sur iPhone ou iPad

      1. Ouvrez cette page dans Safari.
      2. Ouvrez le menu Partager (au besoin, passez par le menu de la page).
      3. Choisissez Sur l’écran d’accueil. Si l’option « Ouvrir comme app web » apparaît, activez-la.
      4. Vérifiez le nom Code secret, puis touchez Ajouter.

      Sur Android ou ordinateur

      Dans Chrome ou Edge, utilisez le bouton d’installation ci-dessus s’il apparaît, ou cherchez « Installer » dans le menu du navigateur ou dans la barre d’adresse. Le nom de l’option varie selon la version.

      Sur Mac avec Safari récent, utilisez Fichier → Ajouter au Dock. Si votre navigateur ne propose pas l’installation, ouvrez le jeu dans Chrome, Edge ou Safari sur un appareil compatible.

      Après l’installation, ouvrez Code secret depuis sa nouvelle icône. Une nouvelle ouverture ou un rechargement démarre une nouvelle partie.
